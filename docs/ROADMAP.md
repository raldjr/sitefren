# Roadmap

Ideas, not promised release dates. Every feature must preserve one clean PHP
upload and readable code without customer-managed workers or build tools.

## Reliability first

- Test live provider routes and representative shared hosting configurations.
- Reduce follow-up output and improve model capability checks.
- Design resumable multi-step edits with saved checkpoints and clear cost controls.
- Show source changes before publishing.

## Hosting experience

- Optional Sheepdog Host provisioning and per-customer key issuance.
- Better automatic compatibility checks and beginner-friendly recovery.
- Safer editor isolation from published website scripts.
- Explicit, conflict-aware import of existing static sites.

## Explore later

- Optional forms and carefully scoped PHP/database applications.
- Update distribution and portable project export.

These are not currently supported features. Open an issue to discuss a proposal
before implementing a major change.
